ArchitectureАрхитектура

AppCoordinator→ ViewController⇄ ViewModel→ Combine→ AuthService / EventService→ Firebase
  • Role-based flow: one coordinator decides onboarding → auth → visitor or organizer tab bar.
  • Сценарий по роли: один координатор решает: онбординг → авторизация → таб-бар посетителя или организатора.
  • Seat limits in a Firestore transaction — sign-ups close atomically when the event is full.
  • Лимит мест в транзакции Firestore — запись закрывается атомарно, когда места кончились.
  • Combine over Firebase callbacks: Future/Deferred publishers, state bound to views.
  • Combine поверх колбэков Firebase: Future/Deferred-паблишеры, состояние привязано к экранам.
  • Unified list states — loading, empty and error-with-retry through one UiStateView.
  • Единые состояния списков — загрузка, пусто и ошибка с повтором через один UiStateView.
  • Typed auth errors (AuthError) instead of one generic message.
  • Типизированные ошибки авторизации (AuthError) вместо одного общего текста.
  • Secrets out of the repo: Firebase config is git-ignored; README explains setup.
  • Секреты вне репозитория: конфиг Firebase в .gitignore, установка описана в README.
